### Description

```text
OSBE Window Resizer gives you repeatable browser and viewport sizes without opening developer tools or typing dimensions every time.

Choose a built-in mobile, tablet, laptop, or desktop preset and the current Chrome window resizes immediately. Each preset can target the complete window or the active page viewport. Add named custom presets using the current target dimensions as a starting point, then edit, reorder, or delete them from the same compact popup.

WHAT IT INCLUDES

- Six built-in device window sizes
- Window or viewport target per preset
- One-click resizing from the toolbar
- Custom presets prefilled from the selected target
- Simple edit, delete, reorder, and reset controls
- Local-only storage
- No account, analytics, ads, tracking, or remote code

Window dimensions include the complete Chrome frame. Viewport dimensions apply to the page area and automatically compensate for browser chrome.

OSBE extensions are open source and focused on one job.
```
