# Chrome Web Store Submission

## Store Listing

### Summary From Package

```text
Resize the current Chrome window from built-in device presets or your own saved sizes.
```

### Description

OSBE Window Resizer gives you repeatable browser sizes without opening
developer tools or typing dimensions every time.

Choose a built-in mobile, tablet, laptop, or desktop preset and the current
Chrome window resizes immediately. Add named custom presets using the current
window dimensions as a starting point, then edit, reorder, or delete them from
the same compact popup.

What it includes:

- Six built-in device window sizes
- One-click resizing from the toolbar
- Custom presets prefilled from the current window
- Simple edit, delete, reorder, and reset controls
- Local-only storage
- No account, analytics, ads, tracking, or remote code

The selected dimensions apply to the complete Chrome window, including its
frame.

OSBE extensions are open source and built to stay small, understandable, and
focused on one job.

## Privacy Practices

### Single Purpose

```text
Resize the current Chrome browser window to a user-selected saved width and height.
```

### Permission Justifications

`storage`

```text
Stores the user's custom window-size presets and preferred preset order locally on their device.
```

Chrome's `windows` API is used to read and update the current browser window
bounds. The API does not require a manifest permission, and the extension does
not request access to tabs, browsing history, or website content.

### Remote Code

Select `No` and use:

```text
The extension does not use remote code. All executable JavaScript and CSS is included in the submitted package.
```

### Data Types

Select no Chrome Web Store user-data categories. Preset names, dimensions, and
ordering are local extension settings and are not transmitted.
