# OSBE Full Page Capture Privacy Policy

Last updated: July 27, 2026

OSBE Full Page Capture creates full-height webpage screenshots when the user
explicitly invokes it. It works locally without an account, analytics,
advertising, or remote sync.

## Information Handled By The Extension

During an active capture, the extension handles:

- Visible page pixels captured from the current tab.
- The page title and URL, used to label the local preview and download.
- Page and viewport dimensions, used to scroll and assemble the image.
- The page's current scroll position and the position of fixed or sticky
  elements, used to avoid duplication and restore the page afterward.

## How Information Is Used

The information is used only to capture the complete vertical page, show its
local preview, and create the PNG or PDF selected by the user. Capture helpers
run only after a toolbar click or configured keyboard shortcut.

## Storage

OSBE Full Page Capture does not store a capture history or page information in
Chrome storage. Captured frames and generated files are held temporarily in
memory by the background worker and result tab. Closing the result tab releases
that data. Files the user downloads are stored wherever Chrome saves downloads.

## Transmission And Sharing

OSBE Full Page Capture does not send page pixels, page content, titles, URLs,
dimensions, downloads, or browsing activity to OSBE or any third party. It does
not sell or share user data and does not use data for advertising, profiling,
creditworthiness, lending, or purposes unrelated to full-page capture.

## Remote Code

The extension does not use remote code. All executable JavaScript and CSS,
including PNG, ZIP, and PDF generation code, is included in the Chrome Web
Store package.

## Limited Use

The use of information received from Chrome APIs adheres to the Chrome Web
Store User Data Policy, including the Limited Use requirements.

## User Control

The extension runs only when the user clicks its toolbar icon or invokes its
keyboard shortcut. Chrome can revoke its temporary page access when the tab is
closed. Users can close the result tab, delete downloaded files, disable the
extension, or uninstall it at any time.
