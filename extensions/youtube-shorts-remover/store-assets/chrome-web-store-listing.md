### Description

```text
Browse YouTube without short-form distractions.

OSBE YouTube Shorts Remover works automatically whenever you visit YouTube. It removes the Shorts navigation entry, Shorts shelves, individual Shorts cards in feeds and search results, Shorts recommendations, and channel Shorts tabs. Direct Shorts pages are redirected away from the Shorts viewer.

There are no menus, accounts, settings, or usage tracking. Install the extension and it immediately keeps Shorts out of the YouTube experience.

The extension runs locally, requests access only to youtube.com, does not store or transmit browsing data, and contains no remote code. Its source code and permission rationale are public in the OSBE repository.
```
