# OSBE YouTube Shorts Remover Privacy Policy

OSBE YouTube Shorts Remover runs locally and does not transmit user data to OSBE.

## What the extension accesses

The extension runs only on `www.youtube.com`. It reads the current YouTube URL
and the page's element structure so it can hide Shorts navigation, shelves,
cards, recommendations, and channel tabs. It redirects direct Shorts URLs away
from the Shorts viewer.

## Storage

The extension has no settings and stores no browsing activity, page content, or
personal data.

## Transmission and sharing

The extension does not transmit page content, URLs, browsing activity, or
personal data to OSBE or any third party. It does not use analytics,
advertising, telemetry, or external services.

## User control

The filtering is active whenever the extension is enabled and a YouTube page is
open. Disabling or uninstalling the extension stops all filtering.

## Remote code

The extension does not execute remote code.

## Limited Use

The use of information received from Chrome APIs adheres to the Chrome Web
Store User Data Policy, including the Limited Use requirements.
