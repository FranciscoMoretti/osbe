# Chrome Web Store Assets

- `store-icon-128.png` is the required Chrome Web Store icon.
- `screenshots/` contains 1280x800 product screenshots without alpha.
- `chrome-web-store-listing.md` is generated from `extension.config.json`.
  Regenerate it with `pnpm extension store-dossier site-blocker`.

Runtime extension icons are sourced separately from `assets/icon.png` by
Plasmo.
